### <samp>// what i work on</samp>

**NumPy** · [all prs →](https://github.com/numpy/numpy/pulls?q=is%3Apr+author%3Aprathamhole14)<br>
At Quansight I'm porting NumPy's C extensions to CPython's **Limited API**, so NumPy can ship `abi3` wheels that build once and keep working on newer Pythons. That means heap types, per-module state and multi-phase module init, and it turned into a side quest: making NumPy safe to use in **subinterpreters**.

**RADIS** · [all prs →](https://github.com/radis/radis/pulls?q=is%3Apr+author%3Aprathamhole14)<br>
A fast line-by-line code for high-resolution infrared molecular spectra. I work on making its big spectroscopy databases (HITRAN, HITEMP, ExoMol) faster to download and parse, using parallel fetching, parallel parsing and vectorised code, and on keeping CI and docs healthy.

**SunPy** · [all prs →](https://github.com/sunpy/sunpy/pulls?q=is%3Apr+author%3Aprathamhole14)<br>
Map plotting, contours, gallery examples and docs.
